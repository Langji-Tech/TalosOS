# 关于朗极智能

**杭州朗极智能科技有限公司**（Hangzhou Langji Intelligent Technology Co., Ltd.）
是 TalosOS 的作者与主要维护方，专注于**机器人基础软件、智能控制系统与
边缘端 AI** 的研发与产品化。

## 我们做什么

- **机器人软件栈**：面向移动机器人、服务机器人与具身智能平台，提供从操作系统、
  通信中间件到感知/规划/控制的全栈解决方案。TalosOS 即是其中的开源部分。
- **智能控制与边缘部署**：在低功耗 / 嵌入式硬件上部署实时控制、多传感器融合
  与 AI 推理，兼顾跨机协同与确定性延迟。
- **定制化系统集成**：为行业客户（物流、工业、服务场景等）提供从硬件选型、
  软件适配到现场调试的端到端交付。

## 为什么构建 TalosOS

过去几年，ROS1 逐步停止维护，ROS2 又带来了较重的构建与运行体系。我们希望
为团队内部的产品线沉淀一个：

- **保留 ROS1 手感** —— `pkg create / build / run / topic / service / launch`
  这些熟悉的命令原样可用；
- **使用现代传输** —— 基于 [Eclipse Zenoh](https://zenoh.io) 的对等发现、
  广域路由与共享内存快路径；
- **工程性友好** —— 单一 `cmake --install` 部署到 `/opt/talosos`，C++/Python
  双语一步到位，支持 bash / zsh。

…的机器人基础软件。**TalosOS 是我们内部工具链中对外开源的一环**，也欢迎
社区复用与反馈。
